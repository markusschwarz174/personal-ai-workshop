# Observer Package

Use this package when the first useful action is to understand what already exists.

## Inputs

- the question to investigate
- the allowed sources or files
- explicit boundaries: what must not be changed

## Route

1. Confirm the observation scope with the HUMAN.
2. Read the relevant evidence.
3. Separate facts, interpretations, and unknowns.
4. Run `SOURCE_CHECK`: every important finding points to evidence.
5. Run `SCOPE_CHECK`: no file, system, or decision was changed.
6. Return an observation report and possible next packages.

## Output

A short report with findings, evidence, uncertainties, and a recommendation. This package is deliberately read-only.
