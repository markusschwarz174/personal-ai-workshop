# Idea Review Package

Use this package for a proposal, workflow, naming system, or product idea that is not yet built.

## Inputs

- the idea in plain language
- the intended benefit
- the people affected
- constraints and known alternatives

## Route

1. Let the HUMAN approve the exact review question.
2. Produce an independent first assessment before comparing it with earlier opinions.
3. Run `EXPERT_REVIEW`: examine usefulness, novelty, complexity, and hidden assumptions.
4. Run `SIMULATION_TEST`: walk through one realistic success case and one failure case.
5. State what evidence could change the verdict.
6. Hand the decision back to the HUMAN.

## Output

A verdict of `CONTINUE`, `SIMPLIFY`, `PAUSE`, or `STOP`, with reasons and the smallest sensible next step.
